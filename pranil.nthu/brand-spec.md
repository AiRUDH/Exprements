# Accretion — Brand Spec

**System:** Interstellar high-energy astrophysics — near-black void, cyan instrument light, academic restraint.

## Type

- Display: `"Space Grotesk", system-ui, sans-serif`
- Body: `"IBM Plex Sans", system-ui, sans-serif`
- Mono: `"IBM Plex Mono", ui-monospace, monospace`

## Posture

1. Academic rigor over marketing — evidence language, no hype metrics.
2. One cyan accent; bloom lives in WebGL, not UI chrome.
3. Calculated scroll pacing — authoritative reveals, not flashy transitions.
4. Glass UI as instrument HUD, not product marketing cards.
5. Finale is a focused beam, not a confetti CTA.
